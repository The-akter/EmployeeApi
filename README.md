## SQALOGY API AUTOMATION PROJECT WITH NEWMAN REPORTING

## About this project 
This is employee API automation project. This project is facilitated  to create employee, update employee data with different parameter. Here we have created automation and 
generate newman reporting. 

## Pre-requisite 
- Node.js

## Tools & Technology
- Postman
- Visual Studio Code

## API Documentation [Employee API Documentation](https://documenter.getpostman.com/view/50520270/2sBYHURyvb)

## How To Run This Project
**```Clone Project```**
```bash 
https://github.com/The-akter/EmployeeApi.git
```

**Hit the command**

```bash
npm init -y
```

```bash
npm i newman
```
```bash
npm newman run [collection] -e ["environment"]
```
```bash
npm i newman-reporter-htmlextra
```
```bash
node .\report.js
```
